## 🎯 Primary Objective

## ✅ Current Priorities (High → Low)

### **P0 - Critical (Do Now)**
1. **Minimal Architecture Cleanup**
   - Split App.tsx just enough to stop pain (NOT perfect refactor)
   - Extract AI logic ONLY if it unblocks speed
   - NO massive rewrite

2. **Cinematic Workspace Shell**
   - Create visual container that feels like production software
   - Cinematic color scheme (dark mode + gold accents)
   - Professional dashboard layout

3. **AI Director Mode Foundation**
   - This is KILLER FEATURE — start early
   - Cinematic breakdown engine
   - Shot list generation
   - Visual mood board
   - Storyboard prompt generator

### **P1 - High Priority**
4. **Cinematic Scene Cards**
   - Visual cards (not text lists)
   - Status badges, character chips
   - Thumbnail/mood visual
   - Quick actions (Draft, Review, Direct)

5. **Scene Timeline**
   - Horizontal draggable timeline
   - Act markers
   - Tension curve overlay
   - Click scene → open workspace

6. **Director Panel**
   - Shot list table (editable)
   - Visual mood suggestions
   - Pacing notes
   - Export to PDF

### **P2 - Medium Priority**
7. **Character Board**
   - Visual character grid
   - Relationship graph (D3.js)
   - Character arc visualization
